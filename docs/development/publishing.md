# Publishing

## Maven Local

- To release library to MavenLocal (~/.m2/):

  ```sh
  ./gradlew releaseToMavenLocal
  ```

## Maven Central

- To release library to [MavenCentral](https://search.maven.org/artifact/com.github.nisrulz/sensey):

  ```sh
  ./gradlew releaseToMavenCentral
  ```
